## 🎮 使用指南

### 模式一：靓号模式 (Leopard/Straight)
自动寻找末尾 N 位相同或连续的地址：
```bash
# 生成末尾 8 位相同的豹子号 (例: T...88888888)
./tulinTron -l 8

# 生成末尾 8 位连续的顺子号 (例: T...12345678)
./tulinTron -s 8
```

### 模式二：匹配模式 (Matching)
通过规则文件进行前后缀精准匹配，支持最多 32 个规则并行：
```bash
# p.txt 格式: 前缀*后缀 (每行一个规则，最多32行)
# 例:
# TABC*XYZ
# T888*666
# T999*999
./tulinTron -m p.txt
```

### 模式三：随机纯数字模式 (Number)
生成末尾 N 位纯数字地址：
```bash
# 生成末尾 15 位纯数字地址
./tulinTron -n 15
```

### 模式四：四模同开 (终极模式) ⭐️ NEW
匹配 + 豹子 + 顺子 + 数字 四种模式同时运行，算力零损耗：
```bash
# 同时运行所有模式，32个匹配规则 + 8位豹子 + 9位顺子 + 15位数字
./tulinTron -m p.txt -l 8 -s 9 -n 15
```

### ✨ 核心优势
- 🔥 32规则并行: 业内唯一支持 32 个前后缀规则同时匹配，速度不降
- 🚀 四模同开: 匹配+豹子+顺子+数字并行，一鱼四吃
- 🧠 智能分拣: 结果自动按 豹子(A/a)、顺子(S/s)、匹配(M)、数字(N) 分类保存至 Result/ 目录
- 🔒 极致安全: 100% 离线生成，硬件级 CSPRNG 随机数，私钥永不上传
- 💪 多卡无损: 支持多显卡协同，算力线性叠加
- 🛡️ 混淆加密: 内置字符串加密，规避杀软误报
