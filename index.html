Guide

多面实战使用教程

第一阶段：运行环境与程序下载

原生兼容多个主流操作系统体系。请在使用前核对以下环境规范：

  • 支持系统：完全兼容 Windows 及 Linux (Ubuntu/CentOS等)。
  • 底层依赖：运行依赖于 NVIDIA 独立显卡，并需安装 CUDA 12.x 工具包。
  • 获取程序：请前往官方频道 @tulinjs 下载最新免安装本。

第二阶段：多模式启动与精准算号

系统支持特征值精准抓取，通过直接下达命令行参数控制，且全面支持安全私钥加密：

  • -s 6 指定顺子号
  • -sn 5 纯数字顺子
  • -l 6 指定豹子号
  • -lf 7 伪豹子号组合
  • -n 8 纯数字地址
  • -m txt 调起多规则自定义

第三阶段：高级进阶（API与流式集群）

针对高端企业与大型算力工作室研发的全集成生态场景：

  • API 接口分发：支持提供 API 给其他服务实时匹配靓号地址，极其完美地无缝对接您的工作室业务流、发卡网或挂机中控系统。
  • 集群化阵列：支持多机集群协作连通，允许多台不同节点共同集中算力执行突破极高难度的单一算号任务。
